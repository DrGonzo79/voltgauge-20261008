# Phased build prompts

1. **Concierge evidence:** Add a private operator queue for paid three-listing briefs. Store source URL, capture time, evidence provenance, and immutable ruleset version. Keep every missing/stale/provider-error state explicit.
2. **One-model diagnostic adapter:** With buyer consent, integrate one approved diagnostic source for one EV model. Reconcile VIN mismatch and conflicting reports; never default absent data to healthy.
3. **Inspector coordination:** Add availability, quote, booking, cancellation, and report ingestion for one metro. Instrument acceptance time, completion, refund, and assessment-vs-inspection disagreement.
4. **Outcome loop:** Collect 30/90-day buyer outcomes, battery findings, and regrets. Calibrate rules with held-out evaluations; AI may summarize evidence but not fabricate or decide.
